# 📰 Pulso News

**Pulso News** é uma aplicação web de notícias em tempo real que agrega as últimas manchetes de diversas categorias, entregando informações atualizadas diretamente para o usuário.

🌍 **Acesso ao projeto em produção:** [https://pulsonews.vercel.app/](https://pulsonews.vercel.app/)

---

## 🚀 Funcionalidades

- **Atualizações em Tempo Real (Ao Vivo):** O feed de notícias é atualizado automaticamente (auto-refresh de 5 em 5 minutos), mantendo você sempre informado.
- **Categorias Dinâmicas:** Filtre rapidamente as notícias por:
  - 🌐 Mundo
  - 🇧🇷 Brasil
  - 💻 Tech
  - 🔬 Ciência
  - 💰 Economia
  - ⚽ Esportes
  - 🎬 Entretenimento
- **Alertas de Urgência:** Banner rotativo na tela principal com destaques para as notícias de última hora.
- **Interface Responsiva:** Layout moderno, escuro e adaptável para funcionar perfeitamente em dispositivos móveis, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais para garantir velocidade e leveza:
- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização responsiva e tema escuro (Dark Mode).
- **JavaScript (Vanilla):** Lógica de consumo de dados, renderização das notícias, filtros por categorias e temporizadores de auto-refresh.
